# Sistema de inventario y ventas para papelería

Aplicación en Python para controlar el inventario y las ventas de una papelería pequeña. Proyecto real, desarrollado para un negocio familiar.

## Qué hace
- Registra productos con precio, existencia y stock mínimo
- Búsqueda por nombre, sin importar mayúsculas ni acentos
- Aviso de productos por agotarse
- Registro de ventas con carrito, por pieza o por caja
- Descuento automático del inventario al vender
- Validación de datos (no permite ventas sin existencia ni valores negativos)

## Cómo ejecutarlo
1. Instala Python 3
2. Descarga `main.py`
3. En la terminal: `python main.py`
