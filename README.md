## Cómo ejecutarlo
1. Instala Python 3 y MySQL Server
2. Instala el conector: `pip install mysql-connector-python`
3. Crea la base de datos ejecutando `schema.sql` en MySQL Workbench
4. En la terminal: `python main.py` e ingresa la contraseña de MySQL
